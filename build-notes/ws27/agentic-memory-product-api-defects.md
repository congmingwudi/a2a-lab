# Agentic Memory and Context product/API defect ledger

Last updated: 2026-11-13

This is the durable index for product defects and contract mismatches discovered by WS27/WS32.
It separates published behavior from tenant observations; a successful response alone is not
treated as proof that an asynchronous write persisted. Org ids, tenant hosts, user ids, and raw
tokens are intentionally omitted. Detailed experiment evidence remains in `plan/03-results.md`.

## Filing discipline

For each new defect, add a row here with a stable ID, then put the exact sanitized request shape,
timestamps, status/body, retry window, and cleanup outcome in `plan/03-results.md`. If a defect is
filed externally, add the case/work-item reference and current owner without copying credentials or
customer data. If later evidence disproves a defect, mark it withdrawn and retain the history (as
the 2026-10-28 Get Context correction in the original filing demonstrates).
