# WS31-b1 implementation notes

## Outcome

Built an eight-scene Agent Memory presentation mode in the existing console shell. It teaches only
the current configured/measured path, labels open boundaries, and hands the presenter to the
existing Claude-teaches or OpenAI-recalls experiment without sending a turn.

## What changed

- Added the Agent Memory group launcher, both scenario-card shortcuts, and contextual experiment
  tab shortcuts.
- Added a declarative eight-scene controller with direct scenes, Previous/Next, arrow navigation,
  ordered Escape precedence, ARIA current/live state, reduced motion, responsive scene rail, and
  stable focus restoration.
- Derived Control Panel suppression only from `view.type === "memory-presentation"`; no persisted
  panel preference is changed.
- Added role-aware scene-8 readiness and live handoff. It validates/preserves the customer, enables
  Memory, uses normal experiment navigation, loads the existing draft, and never calls send.
- Corrected scenario, Details, trace-map, and plan copy to D115's measured registration ×
  server-resolved customer owner × category model and the face-owned isolation boundary.
- Added D116, WS31 item lines, and `plan/20-console-presentation-mode.md`.
- Redacted restricted future-product terminology and source references from served documentation.
