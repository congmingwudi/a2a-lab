## What changed

| Area | Change |
|---|---|
| Reset evidence | `POST /api/memory/customer/{key}` now reports targeted IDs, confirmed-absent IDs, verified/unverified state, and post-reset quarantined-row count without changing D107 `ok` semantics. Failed/incomplete verification returns null counts. |
| Memory manager | Valid-generation rows render as **Quarantined profile rows**; malformed markers get a distinct all-memory-suppressed error. The action is **Start fresh generation**, and its copy distinguishes permanent ID deletion, retained conversation history, and asynchronous re-extraction. |
| Customer Details | All three customer-memory scenarios document that Memory Management DELETE removes listed profile-memory IDs while extraction can create new IDs from retained conversation summaries. |
| Context evidence | Generic Claude/OpenAI responses add complete `context_text = redact(context supplied)` while retaining the legacy 360-character preview. The evidence card prefers the complete value, states `context_chars`, and labels contact-detail redaction. |
| OTLP parsing | `parse_spans()` is shared by the live Session Trace route and optional harvest. It preserves hierarchy, exact integer duration, status, flattened attributes (including bytes/nested values), events/links, resource/scope fields, and the exact raw span. |
| Span drill-down | Every Session Trace row has an accessible **Explain** chip. The modal shows fixture-grounded lab interpretation, parent/children, timing, status, structured attributes, events/links, and the exact raw span. Unknown pairs have an explicit no-interpretation fallback; the full raw session remains below the table. |
| Evidence fixture | `tests/fixtures/agentforce_otel_customer_memory_sanitized.json` preserves the observed names, hierarchy, times, keys and `step.type` values from hosted session `01a1dd0e-6b78-7b4b-910b-762d81f41ddf`, with customer/action values and identifiers replaced. |
| Documentation | D122, WS34 item lines, customer Details, `plan/05-observability.md`, and the L5/L6 deployment map now carry the corrected boundaries. No topology diagram changed. |

## Critique response

| finding | disposition | what changed |
|---|---|---|
| R1 — browser evidence cannot equal the unredacted model context | fixed | The new field is exactly `redact(context supplied)`. The regression extracts the actual context block sent to the inner agent, proves the agent keeps the email tail, proves the browser gets `[REDACTED_EMAIL]`, and checks the entire field for Contact/unified-profile IDs. The label says contact details are redacted for display. |
| R2 — glossary lacked an evidence base | fixed | A sanitized fixture was captured from the user-supplied hosted session. Only observed `(name, step.type)` pairs are registered; the session id is cited in code/D122/fixture. Text is labeled **Lab interpretation**, avoids outcome claims, and unknown pairs fall through honestly. |
| R3 — failed relist and malformed generation were undefined | fixed | Verification counts are null/“unverified” unless a complete post-mutation relist succeeds. The quarantine heading requires a valid generation; malformed state says memory is suppressed for all agents until a valid generation exists. Both branches have regressions. |
| A1/A2 — refine D107 and keep `ok` stable | fixed | D122 explicitly refines D107 and calls counts evidence-only. The existing fresh-reset `ok` expression is unchanged. |
| A3/A4 — shared parser and OTLP edge cases | fixed | Both live and harvest paths call `parse_spans`; duration uses integer nanoseconds, status preserves numeric/string forms, and bytes/array/kvlist values are tested. |
| A5 — size/masking contract | fixed | D122 records 4,000 graph + 4,000 body budgets and at most 20 saved lines. The complete-field regression excludes both raw ids and distinguishes unredacted model context from display redaction. |
| A6/A7 — docs and unknown-span smoke | fixed | `plan/05`, `plan/07`, `plan/09`, Details, and D122 are updated. Unnamed/root spans in the captured session deliberately exercise the unknown fallback during hosted smoke. |
