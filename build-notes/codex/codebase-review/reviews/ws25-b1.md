## Blocking findings

### A1 redaction is unsafe for valid JSON shapes

`src/interop/trace.py:98-110` uses a regex that assumes a secret value is a quoted scalar or an unquoted token. Probes show:

```text
{"client\\u005fsecret":"probe-secret"} -> secret remains
{"password":["first","probe-secret"]} -> malformed JSON and secret remains
{"password":{"nested":"probe-secret"}} -> malformed JSON and secret remains
{"body":"{\\"client_secret\\": \\"prefix\\\\\\\"probe-secret\\"}"} -> secret remains
```

The implementation therefore fails the stated “serialized payload” guarantee at exactly the boundary where trace data can contain nested or structured values. Replace or precede the regex with recursive JSON redaction for parseable payloads, and use a bounded lexical fallback for clipped/malformed strings. Add regression cases for unicode-escaped keys, arrays, objects, nested escaped JSON, and clip-boundary splits. Do not deploy until the fallback never writes a leaked secret or invalidates an otherwise valid payload.

### A3 observability MCP bundle does not cold-start

`src/mcp_http/http.py:69-74` now imports `interop.secret_env`, but `deploy/obs/build_zips.sh:25-29` copies only `interop/trace.py` into the MCP zip. Importing the built bundle therefore raises `ModuleNotFoundError: interop.secret_env` before the handler exists. Copy `secret_env.py`, call `load_secret_env_and_log` before reading the MCP token, and add a test that imports the assembled zip with the same packaging shim.

The handoff also overstates coverage: `src/faces/__main__.py:32-36`, `src/console/app.py:4785-4790`, and `deploy/shim/handler.py:20-25` guard only the ARN path or only load the secret; they do not enforce `A2ALAB_MODE=hosted` through `require_token`. Either wire the common guard into every hosted entrypoint or narrow the claim and tests to the entrypoints actually covered. Test both hosted signals and the explicit `A2ALAB_ALLOW_UNAUTH=1` escape hatch.

## A2 design decisions

1. Put the policy in one shared authorization helper, but perform method classification after the protocol parser where possible. If middleware remains the enforcement point, it must buffer and replay the ASGI body exactly once, preserve `http.disconnect`/`more_body`, enforce a size bound, and have tests for every mounted alias. The current wrapper order places auth outside WireTap, so an untested read can consume the body before the tap or handler.
2. Allow `machine` only on the face/routes used by the Agent Fabric gateway, unless D80 explicitly declares it a lab-wide principal. A global allow is broader than the design's stated attributed-caller model.
3. Keep streaming methods in the deny set only if they are actually routed and tested. Since the lab advertises but does not exercise streaming, either add a route-level test or document that the policy is intentionally future-facing; do not imply runtime coverage.
